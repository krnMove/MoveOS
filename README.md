MoveOS:

Мобильная операционная система, построенная на собственной архитектуре ядра **MoveKernel (ARM64)**.

- **Текущая версия**: 0.2.0 (EL0 Terminal и Move Files)
- **Платформа**: QEMU `virt` (Cortex-A57), ARM64
- **Язык**: Rust (`no_std` / `no_main`)
- **Ядро**: [MoveKernel ARM](https://github.com/krnMove/MoveKernel-ARM)

Возможности:

### Графическая оболочка
- Экран блокировки (Lock Screen) с часами.
- Рабочий стол (Desktop) с сеткой приложений.
- Единый системный статус-бар (часы, Wi-Fi, батарея).
- Единая тёмная палитра и собственный шрифт 5x7.
- Плавные переходы между экранами (Slide).

Приложения:
- **Terminal**: полноэкранная оболочка в пользовательском режиме ARM EL0. Команды: `HELP`, `LS`, `CAT <NAME.EXT>`, `WRITE <NAME.EXT> <TEXT>`, `CLEAR`, `EXIT`.
- **Move Files**: серый двухпанельный файловый менеджер корня FAT32. Слева список с разделителями, справа предпросмотр и ASCII-редактор текстовых файлов. Создаёт пустые файлы 8.3 по клавише `N`.

Ядро (MoveKernel):
- Загрузка в QEMU `virt` (Cortex-A57), свой загрузчик (`boot.s`) и линкер-скрипт.
- Портретное разрешение QEMU 450x800 (9:16); Move Files располагает список и
  предпросмотр вертикально, чтобы использовать ширину экрана телефона.
- ARM MMU: identity-map для RAM, GIC и virtio MMIO; отдельные EL0-доступные страницы кода и данных Terminal.
- Изоляция Terminal: пользовательский код не имеет прямого доступа к памяти ядра или MMIO; экран, клавиатура и ограниченные операции FAT32 доступны через проверяемые системные вызовы.
- GICv3 (Generic Timer отключён).
- Кооперативный планировщик задач.
- Драйверы: virtio-gpu, virtio-input (keyboard/tablet), virtio-blk.
- Сенсорный ввод через `virtio-tablet-device`; экранная QWERTY-клавиатура
  доступна в Terminal и при создании/редактировании файлов.
- Небольшой полупрозрачный указатель следует за движением мыши в QEMU.
- FAT32: чтение, запись, создание и перезапись файлов в корне.
- 1 MiB heap с выравниванием и повторным использованием блоков.

Управление в QEMU:

| Действие | Клавиша |
| :--- | :--- |
| Разблокировать экран | `↑` (Up) |
| Разблокировать свайпом | Свайп вверх на экране блокировки |
| Открыть Terminal | `1` |
| Открыть Move Files | `2` |
| Открыть приложение касанием | Нажать на его иконку |
| Меню иконки | Долгое нажатие: информация или убрать ярлык с рабочего стола |
| Ввод с экрана | Нажимать клавиши QWERTY-клавиатуры в Terminal или редакторе |
| Выбрать файл в Move Files | `↑` / `↓` |
| Редактировать выбранный текстовый файл | `E`; ввод добавляет текст в конец, `Enter` — новая строка, `Backspace` удаляет символ |
| Сохранить изменения | `Ctrl+S`; при выходе с несохранёнными изменениями `S` сохраняет, `D` отменяет |
| Создать файл в Move Files | `N`, затем имя 8.3 + `Enter` |
| Вернуться на Desktop | `Esc` или `Backspace` (из редактора — сначала выйти из редактирования) |
| Выйти из Terminal | `EXIT` или `Esc` |
| Вернуться на Desktop свайпом | Свайп слева направо в Move Files |

Запуск в QEMU:

Соберите ядро и тестовый FAT32-образ с файлом `HELLO.TXT` одной командой:

```powershell
powershell -ExecutionPolicy Bypass -File tools\build-arm.ps1
```

Затем запустите QEMU в портретном разрешении 450x800 (9:16):

```powershell
powershell -ExecutionPolicy Bypass -File tools\run-arm.ps1
```

По умолчанию используется GTK-дисплей. Для запуска через SDL укажите:

```powershell
powershell -ExecutionPolicy Bypass -File tools\run-arm.ps1 -Display sdl
